# Clipboard Shelf

Windows 剪贴板历史工具，带有桌面宠物陪伴。

## 功能

- **剪贴板历史** — 自动记录复制的文字和图片，支持搜索、收藏、批量删除
- **截图** — 框选区域截图，自动保存并 OCR 识别文字
- **图片编辑器** — 画笔、箭头、矩形、文字、高亮、马赛克等标注工具
- **便签** — 彩色便签，支持置顶、自动保存
- **桌面宠物** — 史莱姆宠物，会根据你的使用情况做出反应
- **翻译** — 选中文字或截图自动翻译（中英互译）
- **钉图** — 把图片钉在桌面上，方便参考

## 系统要求

- Windows 10/11 (64位)
- Python 3.x（可选，用于 OCR 文字识别）

## 快速开始

1. 下载 `Clipboard Shelf 1.0.0.exe`
2. 双击运行
3. 程序会在系统托盘显示图标
4. 按 `Ctrl+Alt+Space` 呼出主窗口

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Alt+Space` | 呼出/隐藏主窗口 |
| `Ctrl+F` | 聚焦搜索框 |
| `↑↓` | 选择记录 |
| `Enter` | 复制选中项 |
| `Delete` | 删除选中项 |
| `Esc` | 清空搜索/关闭窗口 |
| 双击 | 复制文字 / 打开图片编辑器 |

## 功能说明

### 剪贴板监听
程序启动后自动监听剪贴板，复制的文字和图片会自动保存到历史记录。

### 截图
点击状态栏的相机图标，拖拽选择区域，截图会自动保存并尝试 OCR 识别文字。

### 图片编辑器
双击图片打开编辑器，支持：
- 画笔、箭头、矩形、椭圆、直线
- 文字、高亮、马赛克、序号标注
- OCR 提取文字
- 翻译

### 便签
点击状态栏的便签图标切换到便签面板，支持：
- 创建彩色便签
- 置顶重要便签
- 自动保存

### 桌面宠物
鼠标离开主窗口时，会收起为桌面宠物。宠物会：
- 对你的复制操作做出反应
- 根据心情显示不同表情
- 在桌面上自由行走

### 钉图
右键点击图片，选择"钉到桌面"，图片会钉在屏幕上：
- 拖拽移动
- 滚轮缩放
- 双击关闭

### 翻译
在图片编辑器中，可以：
- 全图 OCR 后翻译
- 框选区域 OCR 后翻译

### 配置导入导出
在设置中可以：
- 导出收藏和便签到 JSON 文件
- 从备份文件导入

## OCR 功能（需要 Python）

截图和图片编辑器的 OCR 功能依赖 Python：

1. 安装 Python 3.x（https://python.org）
2. 确保 `python` 或 `py` 命令可用
3. 程序会自动检测 Python 路径

如果没有安装 Python，其他功能不受影响。

## 数据存储

所有数据存储在：
`%APPDATA%/clipboard-shelf/`

- `shelf.db` — 剪贴板历史数据库
- `images/` — 截图和图片
- `config.json` — 配置文件
- `crash.log` — 崩溃日志

## 常见问题

### Q: 为什么 OCR 识别不了？
A: 请确保已安装 Python 3.x，并且 `python` 或 `py` 命令可以在命令行中使用。

### Q: 如何开机自启？
A: 在设置中开启"开机自启"选项。

### Q: 快捷键冲突怎么办？
A: 目前快捷键固定为 `Ctrl+Alt+Space`，暂不支持自定义。

### Q: 如何完全退出程序？
A: 右键点击系统托盘图标，选择"退出"。
