========================================
  Clipboard Shelf 使用说明
========================================

【简介】
Clipboard Shelf 是一款 Windows 剪贴板历史工具，
自动记录你复制的文字和图片，还带有可爱的桌面宠物。

【安装】
1. 下载 Clipboard Shelf 1.0.0.exe
2. 双击运行（不需要安装）
3. 程序会在右下角系统托盘显示图标

【基本使用】
• 按 Ctrl+Alt+Space 呼出主窗口
• 鼠标离开窗口会自动收起为桌面宠物
• 再按 Ctrl+Alt+Space 或点击宠物展开窗口

【功能】

📋 剪贴板历史
  • 复制的文字和图片自动保存
  • 在搜索框输入关键词搜索
  • 点击星号收藏重要内容
  • 选中后按 Delete 删除

📸 截图
  • 点击状态栏相机图标
  • 拖拽选择截图区域
  • 截图自动保存并识别文字

✏️ 图片编辑
  • 双击图片打开编辑器
  • 支持画笔、箭头、文字等标注
  • 可以提取文字和翻译

📝 便签
  • 点击状态栏便签图标
  • 创建彩色便签
  • 支持置顶和自动保存

🐾 桌面宠物
  • 鼠标离开窗口变成宠物
  • 宠物会根据你的操作做出反应
  • 拖拽宠物可以移动位置

📌 钉图
  • 右键点击图片
  • 选择"钉到桌面"
  • 图片会钉在屏幕上方便参考

【OCR 文字识别】
截图和图片编辑的 OCR 功能需要 Python：
1. 安装 Python（python.org）
2. 确保 py 或 python 命令可用
没有 Python 不影响其他功能。

【快捷键】
  Ctrl+Alt+Space  呼出/隐藏窗口
  Ctrl+F         搜索
  Enter          复制选中项
  Delete         删除选中项
  Esc            关闭/清空搜索

【设置】
点击状态栏齿轮图标：
• 开机自启
• 最大记录数
• 配置导入导出

【退出程序】
右键点击系统托盘图标 → 退出

【数据位置】
%APPDATA%\clipboard-shelf\
